🔧 Einstellungen

Links / Rechts zum Anpassen. Dimmt die Darstellung, nicht die TV-Hintergrundbeleuchtung.

Tastenbelegung

Während der Diashow:

Links / Rechts
Vorheriges / nächstes Bild
Hoch / Runter
Bildinformationen ein / ausblenden
OK / Enter
Anderer Rahmen

Andere Passepartout-Farbe
Gelb / P+ · Blau / P−

Zurück / Rot

Hoch länger als 3 Sekunden

Tastatur: M / Esc = Menü · G / Leertaste = Farbe · D / A = Anzeigezeit länger / kürzer · N = neu mischen.

Im Menü: Pfeiltasten bewegen den Fokus, OK aktiviert das markierte Feld. Beim Helligkeitsregler ändern Links / Rechts den Wert; Hoch / Runter verlassen den Regler. „Speichern“ und „Zurück“ in der Menüleiste schließen die Einstellungen und übernehmen Änderungen. Die Zurück-Taste der Fernbedienung macht dasselbe.

Touch auf dem Bild: Links / rechts wischen oder die seitlichen Viertel antippen = Bildwechsel. Mitte antippen oder nach unten wischen = Menü. Unteres Viertel antippen oder nach oben wischen = Bildinfos ein / aus. Im Menü kannst du normal tippen und scrollen.
